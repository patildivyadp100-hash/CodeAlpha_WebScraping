CodeAlpha Web Scraping Project
Project Overview

This project is created as part of the CodeAlpha Data Analytics Internship – Task 1: Web Scraping.

The project uses Python and BeautifulSoup to scrape publicly available book information and create a custom dataset.

Technologies Used
Python
Requests
BeautifulSoup
Pandas
Matplotlib
Dataset

The dataset contains information about 20 books.

Columns
Book Name
Price
Rating
Project Files
scraper.py – Web scraping code
analysis.py – Data analysis and visualization
books_dataset.csv – Scraped dataset
rating_distribution.png – Rating distribution graph
Analysis Results
Total Books: 20

How to Run

Install the required libraries:

pip install requests beautifulsoup4 pandas matplotlib

Run the scraper:

python scraper.py

Run the analysis:

python analysis.py
